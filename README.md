# CodeSprint 2026 – Hackathon Landing Page

A simple landing page for a college Coding Club hackathon, built with plain HTML, CSS and JavaScript.
This repository was made to practise Git and GitHub: branching, committing, merging and resolving a merge conflict.

## Features
- Hero section with a live countdown to the event
- About section with the three tracks
- Event schedule
- Registration form with a confirmation message

## How to run
Open `index.html` in any browser. No installation is needed.
